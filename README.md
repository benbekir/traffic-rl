# Adaptive Traffic Light Optimization using Deep Reinforcement Learning and SUMO
Deep Reinforcement Learning for Adaptive Traffic Light Optimization using SUMO simulations.

## SUMO
To create networks and run simulations, you need to have SUMO (Simulation of Urban MObility) installed on your system. You can download it from the official website: [https://eclipse.dev/sumo/](https://eclipse.dev/sumo/).
